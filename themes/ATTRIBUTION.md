# Theme attribution

Except for Hermarchy and nblight, the `colors.toml` files in this directory come from
<https://github.com/basecamp/omarchy>. They are MIT-licensed, Copyright (c)
David Heinemeier Hansson.
The complete upstream notice and permission text is retained in
[`LICENSES/THIRD_PARTY_MIT.md`](../LICENSES/THIRD_PARTY_MIT.md).

`themes/hermarchy/colors.toml` is an nbshell adaptation and the three converted
wallpapers under `wallpapers/hermarchy/` come from the MIT-licensed community theme
<https://github.com/archer-clawbot/omarchy-hermarchy-theme>, reviewed at commit
`12f3c5257f87237fa3fd549cf7be3f9fba76f9c8`, Copyright (c) 2026 Archer
Clawbot. The original 3840x2400 PNG artwork was center-cropped to 16:9,
resized to 1920x1080, stripped of metadata, and encoded as WebP for nbshell.
Its license is retained in [`themes/hermarchy/LICENSE`](hermarchy/LICENSE).
The adapted palette keeps Hermarchy's near-black workstation base while using
brighter Catppuccin-leaning blue, mauve, teal, green, amber, and red roles so
the existing nbshell surfaces remain easier to scan without adding UI.

No Hermarchy agent collector, independent poller, Omarchy shell configuration,
Hyprland configuration, or Hyprlock configuration is included. The optional
`hermarchy-agent` comparison widget reimplements only the compact semantic
signal on nbshell's existing resident Hermes data. It is disabled by default;
the full native AI module remains unchanged. The selected palette also reaches
Hermes through the existing optional theme hook.

To refresh the color files from an Omarchy checkout:

```bash
for t in <omarchy-repo>/themes/*/; do
  mkdir -p "themes/$(basename "$t")"
  cp "$t/colors.toml" "themes/$(basename "$t")/"
done
```

## nblight

`themes/nblight/colors.toml` is nbshell's paper-inspired adaptation of the
locally installed Harbor palette. It adapts Harbor's paper background toward warmer, slightly darker
parchment and retains its dark green ink, with darker accents, secondary text,
and explicit light surfaces. It was developed under the working name Harbor Paper.

The four wallpapers in `wallpapers/nblight/` were generated by the project
owner with Midjourney for nbshell on 2026-09-10 and contributed for inclusion
in the shell. No wallpapers from the original Harbor theme are bundled.
See [`wallpapers/MIDJOURNEY-PROVENANCE.md`](../wallpapers/MIDJOURNEY-PROVENANCE.md)
for the source mapping.

## nbdark

`themes/nbdark/colors.toml` uses the bundled Catppuccin Mocha palette unchanged
under nbshell's companion-theme name. Its palette has the same source and MIT
notice as `themes/catppuccin/colors.toml`, described above.

The two original `wallpapers/nbdark/` terminal illustrations were generated
by the project owner with Midjourney on 2026-09-10 and contributed under the
repository's MIT license; see the wallpaper provenance file.

### Window-frame palette options

Themes may set `inactive_border_color` and `outer_border_color` separately
from text colors, plus `border_width` (rounded and limited to 1–8 pixels).
Omitting these keys preserves the existing frame export. nblight uses a
four-pixel petrol focus frame with quiet parchment-colored inactive and
outer borders; nbdark keeps its existing frame styling.
