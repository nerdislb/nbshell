# Mail and WhatsApp integration update — 2026-09-11

Mail now follows upstream `5953da41ed041b8e0279e03c8be63ec05cbb1271` (0.8.2 plus subsequent fixes). The former catalog marker `6fdf290` recorded an audit, not an imported base; the actual nbshell port derived from `f69df2d` (0.6.0). The update preserves the native Mail cell, the nbshell open/close and mailto contracts, theme/font roles, accessible labels, plain text rendering and opt-in local contact discovery. Outlook OAuth, JMAP, unified views, multi-selection, cursor previews and provider improvements come from upstream. The optional user-invoked Claude bridge reads `nbshell agent default`; it does not install an agent or change its system profile.

The security boundary changes are imported together: verified raster image data and checked/pinned public HTTP destinations; no redirect following for remote images or unsubscribe; complete curl-config field validation before spawning curl; JMAP discovery credential gating; CalDAV same-origin writes; local-link blocking; attachment content checks before external opening. Sender-controlled content remains data and credentials remain on stdin/keyring paths. These are scoped changes, not a claim of a complete audit of every supported mail provider.
