# Security

Do not report security problems in a public issue. Use GitHub's private
**Security → Report a vulnerability** feature in this repository or email
`security@nbsystems.dev`. Include the affected nbshell version, a concise
reproduction, and the impact. Do not attach real credentials or private logs.

Security reports cover the current prerelease and the latest commit on `main`.
Older beta builds may be asked to update before a report is investigated.

nbshell runs local helper scripts and can install optional plugins from Git
repositories. Only install plugins from sources you trust. Never include API
keys, tokens, calendar URLs, or other credentials in issues, logs, or pull
requests.
